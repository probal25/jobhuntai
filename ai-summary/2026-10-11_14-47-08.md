# Project State Summary - 2026-10-11_14-47-08

## 🎯 Project Goal
Build an autonomous job application pipeline: LinkedIn Scraping $\rightarrow$ Local LLM Triage $\rightarrow$ Tailored LaTeX Resume PDF generation.

## 🛠️ Technical Stack
- **Backend:** Spring Boot 3.4.x, Java 17
- **AI:** Spring AI + Ollama (Local LLM)
- **PDF:** `pdflatex` via custom LaTeX template
- **Storage:** MySQL / Spring Data JPA
- **Scraping:** Jsoup

## 🚀 Recent Fixes & Improvements
- **LaTeX List Formatting (Resolved):**
    - Implemented **Few-Shot Prompting** in `ResumeAdapterAgent.java` to force the model to use `\resumeItem` and `\resumeItemTech`.
    - Added a **Robust Post-Processing Guard** with unicode bullet support (`•`, `·`) and regex-based replacement to handle leading whitespace.
    - Forced the bullet label in the LaTeX template: `\begin{itemize}[label=$\bullet$]`.
- **Tech Stack Styling (Resolved):**
    - Modified `\resumeItemTech` to use `\item[]` to remove the bullet point from technology lists.
- **Visual Polish (Resolved):**
    - Adjusted `\resumesection` vertical spacing (`\vspace{2pt}`) to prevent the horizontal divider line from overlapping with section headlines.
- **Observability:**
    - Added `log.info("RAW LLM OUTPUT...")` in `ResumeAdapterAgent` to capture raw model responses for debugging.

## ⚠️ Current Status / Pending Goal
- **Goal: One-Page Resume**
    - The objective is to implement content compression (e.g., limiting bullet points, removing irrelevant sections like "Projects" when experience is strong) and template optimization (reducing margins/spacing) to ensure a strict one-page limit.
